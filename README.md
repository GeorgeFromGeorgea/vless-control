# VLESS Control

VLESS Control — экспериментальная панель управления VLESS-пользователями через Telegram. Установщик рассчитан только на *чистый Ubuntu или Debian* и создаёт отдельную конфигурацию Xray с одним VLESS/TCP inbound (`security: none`). Не запускайте его на сервере с уже настроенным Xray: установщик откажется при обнаружении существующего бинарника, конфига или systemd-службы. Он не импортирует и не заменяет действующую конфигурацию.

Поддерживаются Ubuntu и Debian с `apt-get` и systemd. Проверьте доступность выбранного TCP-порта в firewall VPS и панели хостинга; успешная установка не гарантирует доступность из интернета или конкретной сети.

## Подготовка и установка

Нужны root/sudo, интернет, Telegram bot token (создайте бота через `@BotFather`), числовой Telegram ID администратора и публичный IP/hostname сервера, по которому клиенты будут подключаться. Установщик интерактивно запросит токен (скрытый ввод), ID, публичный адрес и порт (по умолчанию 443). Токен и параметры попадут в `.env` с правами доступа только владельцу.

### Обязательная проверка сервера перед установкой

Установщик рассчитан на чистый сервер. После клонирования проекта, но **до** запуска установщика, выполните одну понятную проверку:

```bash
bash check-server.sh
```

Скрипт только читает состояние сервера: ничего не останавливает, не устанавливает и не меняет. Он выводит:

- занятые важные порты и службу-владельца (`Xray`, `nginx`, `Apache`, Docker и другие);
- пометку `только локально` или `внешний интерфейс`;
- найденные службы Amnezia/Xray/VPN;
- запущенные Docker-контейнеры и их порты;
- рекомендуемые TCP-порты для нового профиля.

Пример понятного результата:

```text
ЗАНЯТЫЕ ПОРТЫ
- 443/tcp — Xray, внешний интерфейс
- 80/tcp — nginx, внешний интерфейс
- 8088/tcp — nginx, внешний интерфейс
- 10001/tcp — Xray, только локально
- 10085/tcp — Xray, только локально
- 8080/tcp — Apache, только локально
- 51820/udp — порт свободен или не найден среди занятых

СЛУЖБЫ VPN/XRAY
- xray.service — active (Xray)

ИТОГ: если найден действующий Xray, второй Xray не устанавливать.
```

Проверьте прежде всего порты `80/tcp`, `443/tcp`, `8443/tcp` и `51820/udp`. Установка возможна только на чистом сервере: без существующего Xray, его конфига и systemd-службы. Если нужный порт занят, не останавливайте службу вслепую — используйте существующую конфигурацию или отдельный сервер.

Рекомендуемые порты: `443/tcp`, если он свободен; затем `8443/tcp`, `2053/tcp`, `2083/tcp`, `2087/tcp`, `2096/tcp`; запасной вариант — свободный порт из диапазона `10000–20000/tcp`. Выбранный порт также должен быть открыт в firewall и панели VPS.

### Открытие выбранного порта после проверки

Открывайте порт только если он выбран для Xray и действительно нужен. Ниже пример для `8443/tcp`; замените `8443` на свой порт.

**1. Проверка локального firewall UFW:**

```bash
sudo ufw status verbose
```

Если UFW включён (`Status: active`), добавьте правило и убедитесь, что SSH не заблокирован:

```bash
sudo ufw allow 8443/tcp
sudo ufw allow 22/tcp
sudo ufw status numbered
```

Если UFW не установлен или выключен, не включайте его вслепую. Проверьте правила nftables:

```bash
sudo nft list ruleset
```

**2. Открытие в панели VPS:**

В разделе `Firewall`, `Network`, `Security Groups` или `Правила входящего трафика` добавьте:

- протокол: `TCP`;
- порт: выбранный порт, например `8443`;
- источник: `0.0.0.0/0`;
- действие: `Allow`/`Разрешить`.

Для IPv6 добавьте отдельное правило с источником `::/0`, только если IPv6 используется на сервере.

**3. Проверка после запуска Xray:**

```bash
sudo ss -lntp | grep ':8443'
```

В выводе должен быть Xray, слушающий выбранный порт. Если порт открыт в UFW, но закрыт в панели VPS, внешнее подключение всё равно не пройдёт. Открытый порт также не подтверждает работоспособность VLESS без проверки клиентом.

```bash
git clone https://github.com/GeorgeFromGeorgea/vless-control.git
cd vless-control
bash check-server.sh
sudo ./install.sh
```

Установка проверяет платформу, наличие Xray-конфигов/бинарников/systemd-служб и занятость TCP-порта до установки зависимостей. При любом обнаруженном Xray, конфиге или unit-файле прекращает работу, не пытаясь «починить» или заменить его. На чистой системе загружает официальный релиз Xray с проверкой SHA-256, создаёт конфигурацию с тегом `vless-control-managed` и параметрами VLESS/TCP без TLS/REALITY (`security: none`), проверяет её через `xray run -test`, затем создаёт `.env` и unit-файлы без перезаписи существующих файлов.

После установки службы *не запускаются*. Только явный ввод `YES` в ответ на отдельный запрос включает автозапуск и запускает Xray и бота. Иначе службы остаются остановленными и выключенными. Порт должен быть открыт в системном и внешнем firewall. Такая конфигурация plain VLESS не обеспечивает транспортное шифрование; используйте её с пониманием этого ограничения.

## Работа с ботом

После запуска откройте боту личный чат и отправьте `/start`. Доступ разрешён только ID из `TELEGRAM_ADMIN_IDS`. Кнопка **Получить ключ** просит метку и срок действия: 1, 7 или 30 дней либо бессрочно. Она создаёт индивидуальный UUID, назначает управляемый профиль и применяет клиента в Xray; ссылка показывается администратору в приватном чате.

В панели доступны список пользователей и ключей, создание профилей, назначение профилей и выдача ссылок. Раздел **Управление ключами** позволяет выбрать пользователя и безопасно отключить/включить его, отозвать все ключи, удалить отдельный профильный ключ или удалить запись пользователя — операции подтверждаются и применяются к Xray до завершения. Удаление профильного ключа отзывает только один профиль; при наличии TCP и WS отключение пользователя удаляет его из обоих входящих профилей. Кнопка **Мониторинг** показывает наличие активной сессии по Xray Stats API; если Stats не включены или API недоступен, статус выводится как неизвестный, а не как офлайн.

Ссылки `vless://` и UUID являются секретами доступа. Передавайте их только конечному пользователю приватно. Ключ WS-профиля работает в приложении **Happ** и других клиентах с поддержкой VLESS/WS.

### Приложения для подключения

- **Happ** — [официальный сайт и загрузка](https://happ-proxy.com/)
- **Hiddify** — [официальный сайт](https://hiddify.com/) и [релизы](https://github.com/hiddify/hiddify-app/releases)
- **v2rayNG** (Android) — [релизы GitHub](https://github.com/2dust/v2rayNG/releases)
- **v2rayN** (Windows) — [релизы GitHub](https://github.com/2dust/v2rayN/releases)
- **Streisand** (iOS) — [App Store](https://apps.apple.com/app/streisand/id6450534064)

В приложении выберите импорт из буфера обмена или QR-кода и вставьте ссылку `vless://`. Для текущего рабочего WS-профиля должны сохраниться: тип `ws`, путь `/vless-ws`, порт `8088`, TLS/security `none`. Это минимальная текущая реализация; доступность конкретного сервиса также зависит от его региональных ограничений, аккаунта и репутации IP-адреса сервера.

## Команды Telegram-бота

Все команды доступны только администратору из `TELEGRAM_ADMIN_IDS` и в личном чате с ботом:

- `/start` — открыть главное меню.
- `/users` — список пользователей без UUID.
- `/profiles` — список активных профилей и портов.
- `/new_user ИМЯ` — создать запись пользователя. Для обычной выдачи используйте кнопку **Получить ключ**: профиль назначается автоматически.
- `/links USER_ID` — показать ссылки активных профилей пользователя. Ссылки являются секретами.
- `/revoke USER_ID` — запросить отключение пользователя.
- `/revoke confirm USER_ID` — подтвердить отключение пользователя.
- `/cancel` — отменить текущее действие и очистить состояние формы.



- Установщик предназначен для чистого Ubuntu/Debian. Существующий Xray, его конфиг или unit — безусловный отказ; для уже работающего сервера используйте отдельную проверенную процедуру миграции, не этот установщик.
- Установщик и runtime согласованы по тегу и параметрам inbound: plain VLESS/TCP, `security: none`. `XRAY_MANAGED_PROFILE_TAG` задаётся в `.env` и в конфиге Xray; `XRAY_MANAGED_VLESS_PORT` задаёт порт. Не меняйте их несогласованно.
- DNS, firewall/security group и внешний доступ к порту автоматически не настраиваются.
- Не помещайте `.env`, UUID, ссылки и Xray-конфиг в Git или общедоступные чаты. Проверьте подключение на отдельной тестовой VM до практического использования.

## Тесты

```bash
python3 -m venv .venv
. .venv/bin/activate
python -m pip install -e .
python -m unittest discover -s tests -v
python -m compileall -q vless_control tests
bash -n install.sh
```

## Диагностика

```bash
sudo systemctl status xray --no-pager
sudo systemctl status vless-control --no-pager
sudo journalctl -u xray -n 100 --no-pager
sudo journalctl -u vless-control -n 100 --no-pager
```

Остановить и отключить автозапуск:

```bash
sudo systemctl disable --now vless-control
sudo systemctl disable --now xray
```
